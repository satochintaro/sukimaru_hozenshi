# スキマル保全士 Ver 5.4.0 TEST

## 追加機能
- 年度別過去問の個人成績履歴（最新・最高・挑戦回数・前回比）
- Playerホーム「今日のコーチ」
- 学科＋実技を共通テーマで総合分析
- 成績向上時の褒めメッセージ
- バッジ（100問、500問、1000問、7日連続、過去問80点、7年度、実技80%、10点UP）
- 試験日カウントダウン
- Manager「総合分析」タブ
- Manager→Player 個別メッセージ
- Manager→全員 一斉メッセージ
- Managerから試験日設定

## Supabase
`COACH_SETUP.sql` をSupabase SQL Editorで1回実行すると、試験日とManagerメッセージが有効になります。
SQL未実行でも、年度別成績・今日のコーチ・バッジは端末内で動作します。

## 注意
過去問履歴はVer 5.4導入後に「年度別過去問 本番100問」を完走した結果から蓄積されます。
Manager側で履歴を見るには、Playerが学科成績をクラウド提出した時点で同期されます。
