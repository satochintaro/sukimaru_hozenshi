【適用方法】
1. ZIPを展開する。
2. jitugi-2023.html と practical-2023-v9 で始まる全ファイルを、GitHubリポジトリ satochintaro/sukimaru_hozenshi のルートへ配置する。
3. jitugi-2023.html は既存ファイルに上書きし、追加ファイルもすべてアップロードする。
4. GitHub Pagesの更新後、実技メニューから2023年度を開き直す。
※ ZIP内に階層フォルダはありません。中身のファイルをルートへ配置してください。
※ v8導入済みの状態から適用できます。古いJS/CSSの削除は不要です。
