# スキマル保全士 v16.60

## 原因と修正
公開中v16.59のHTMLには入口がありましたが、共通styles.cssの section { display:none; height:100dvh; } が適用され、実ブラウザの計算結果は display:none でした。
開発者の入口だけ display:block; height:auto; flex:none を明示し、非表示と画面全高の指定を解除しました。共通CSS自体と学習画面の表示切替は変更していません。

## 反映

開発者画面の上部タブと見出しの下に「限界チャレンジを開く」「開発者用の入口 · v16.60」「2級を開く／1級を開く」を表示する修正です。
ZIPに含まれない既存の問題・画像は削除しないでください。学習記録・サイトデータの削除やSQL実行は不要です。

## 確認範囲
公開中ページの実ブラウザで入口の存在、display:none、適用元CSSを確認して原因を特定。修正版HTMLの明示指定とリンク、構文・ZIP整合性を確認。修正版の公開後表示と本番ログイン後のプレイは未確認です。
