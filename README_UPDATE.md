# スキマル保全士 v16.56 更新版

## アップロード
このZIPを展開し、既存の公開フォルダへ上書きしてください。
- ルートの index.html / manifest.webmanifest / service-worker.js とアイコン画像を同じ階層へ。
- app フォルダ内は既存の app フォルダへ上書き。
- 既存フォルダや、今回のZIPに含まれない問題・画像ファイルは削除しないでください。
- アプリ・ブラウザのサイトデータを削除する必要はありません。

## 変更内容
タイトル・級選択・1級・2級学科・2級実技で、同じメニューを開きます。

メニューには登録情報、連絡、表示・出題設定、データ管理をまとめました。
従来の大きなバックアップパネル、常時表示されるプレイヤーNo.・長い説明・重複した設定画面を整理しています。
- 表示・出題設定：文字サイズ、コントラスト、誤答の印、自動フォロー、動きを控えめにする設定、通知・バッジ設定。
- データ管理：No.・最終同期状態、復旧コード、以前の登録の復元、端末データのファイル保存。
- データ利用説明はデータ管理内で折りたたみ表示。
- 通常メニューには学習履歴のリセット操作を出しません。
- 1級と2級の既存設定値を維持し、開いている級の設定を変更します。タイトルでは最後に選んだ級を対象とします。

## アプリとホーム画面アイコンの更新
メニューの「更新を確認」で更新画面を開き、再度「更新を確認」を押すと通信・公開ファイルを確認します。
確認後の「更新して開き直す」で、学習記録の同期用スナップショットを端末へ保存してから再読み込みします。未送信の記録を消しません。

manifestのアプリID・scopeは維持し、アイコンURLにバージョンを付け、再取得可能にしました。今回の絵柄は変更していません。
今後、アイコンの絵柄を変えるリリースでは、新しいURLも付けてください。
- Android：ブラウザ・OSによる反映待ちや、アプリ更新の確認操作が発生する場合があります。
- iPhone：追加済みアイコンの差し替えをWebアプリ側から強制・保証できる仕組みではありません。
- アプリ本体の更新完了と、ホーム画面アイコンの反映は別です。
- アイコンだけのために既存アプリやサイトデータを削除しないでください。
