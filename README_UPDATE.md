# スキマル保全士 v16.63 成績ダッシュボード

## 今回の変更

- 管理者・開発者とも最初の画面を「成績」に統一。登録者、平均正答率、85%以上の人数、75%未満の人数を表示。
- 閲覧数・タップ数・権限表示・同期の詳細表・AI教育案内などを成績画面から除き、登録者と正答率の確認に集中する構成。
- 正答率の推移は縦軸50〜100%に固定。85%の目標合格ラインは緑、75%の最低ラインは黄の破線と帯で表示。85%・75%はアプリの学習管理目標。
- 75%未満は赤、75〜85%未満は黄、85%以上は緑。未学習は「—」で表示し、0%として平均に混ぜない。
- 全体推移は正解数÷回答数で加重集計。日付は日本時間。記録のない日は直前の値を引き継ぎ、初回記録前は欠測にする。50%未満の値は下端の▼にし、実値を日別表と個人一覧で確認可能。
- 学科・実技・総合、1級・2級、7・30・90日、名前検索、正答率・回答数・更新日での並べ替えに対応。
- 名前を押すと個人の推移グラフを表示。登録者は未学習者も含める。登録情報は1・2級共通。
- 管理者はログイン拠点のみ。開発者は全拠点を選択可能。登録者管理、復旧、連絡、運用設定は既存の権限を維持。
- 開発者の限界チャレンジ入口は「設定」に集約。既存の記録・解放条件は変更しない。
- 管理者用の拠点内登録者取得関数は適用済み。追加のSQL実行は不要。

## 引き続き含むテンポ改善

- 正解時の演出停止を1.45秒から0.32秒、10問ごとを2.85秒から0.65秒へ短縮。

- 通信・端末の状態によって図の初回読込、開発者権限の確認には待ち時間が残る場合があります。
