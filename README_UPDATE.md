# スキマル保全士 v16.62 上位5名のランキング

- 上位5名を常時表示。1〜3人目は表彰台、4〜5人目も専用カードで強調。
- 6人目以降は「続きのランキングを見る」をタップして展開。取得上限は従来の100人。同順位・100人圏外の本人順位を維持。
- サーバー集計の不具合は修正済み。確認時点で2級8人分の記録が集計対象になっています。認証・実行権限は維持、記録自体の変更・削除なし。SQL実行は不要です。
- 更新画面でアプリ内容の更新とアイコン変更を区別。iPhoneの既存アイコンをWebアプリから強制変更する機能はありません。Androidもブラウザ側の更新タイミングに依存します。
- アイコン追加前に復旧コードとバックアップを確認する導線を追加。新しい入口で0問・新規登録画面が出たら登録し直さず元の入口へ戻る案内を追加。古いアイコンやサイトデータを先に削除しないでください。

ランキング描画は0〜5・8・100人、同順位、本人圏外、HTMLエスケープを模擬環境で検証。サーバー関数は無認証の呼び出し拒否と既存の権限・認証ガード維持を確認。スマホ実機の新レイアウトとアイコン反映は未確認です。

## 引き続き含むテンポ改善

- 正解時の演出停止を1.45秒から0.32秒、10問ごとを2.85秒から0.65秒へ短縮。
- 正解と次の問題への進行を1回の保存で確定。開発者の権限確認は従来どおり各回答で行い、画面切替時の重複確認・保存を除去。
- 現在の問題から先5問分の図を先読み。同じURLの重複読み込みを抑制。
- 通信・端末の状態によって図の初回読込、開発者権限の確認には待ち時間が残る場合があります。
- 過去の途中記録（正解演出中の記録も含む）は既存の再開処理を維持。
- 前版の開発者入口非表示修正、タイトルキャラと演出を含みます。
