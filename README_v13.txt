スキマル保全士 他拠点展開版 v13

導入方法
ZIPを展開し、中のファイルを現在のアプリのプロジェクト直下へ上書きしてください。
既存の supabase-config.js、問題データ、既存CSS等を残して使用する更新パッケージです。
上書き後にサイトを公開し、index.htmlのURLを配布します。
このZIPの作成時点では、サイトへの上書き・公開は実施していません。
登録・削除に必要なクラウド側の設定は既存プロジェクトに適用済みです。
ROLLOUT_SETUP_v13.sqlは設定内容の記録です。現在のプロジェクトで再実行する必要はありません。

展開担当者の準備
1. サイトを更新・公開する。
2. マネージャー画面の「展開用URLをコピー」で配布URLを取得する。
3. プレイヤー用・マネージャー用PDFのURL欄に配布URLを記入して共有する。
4. 管理者には共通パスワード bathlife を別途案内する。
5. 最初の利用者に登録、ホーム画面追加、成績提出まで実施してもらう。

変更内容
・名前と所属拠点をクラウドに登録するまで、学習画面を操作できません。
・既存利用者もv13への更新後に一度、名前・拠点を確認して登録します。
・登録内容はトップに常時表示せず、歯車から確認・変更します。
・成績提出前の登録者も開発者の一覧に表示します。
・開発者は対象者ごとに登録情報・提出成績・個別メッセージを削除できます。
・対象者の表示名を入力して確認する方式です。一括削除ボタンはありません。
・削除済みのプレイヤーNo.による再送信・再登録を拒否します。
・v13で登録した対象端末は、次回オンライン確認時に登録とローカル学習履歴を消去します。
・他の登録者のデータは削除しません。既存の実利用者は今回削除していません。
・プレイヤー用・マネージャー用のアプリ内説明、印刷用HTML、A4各1ページのPDFを同梱。
・トップと登録完了画面にホーム画面追加の入口を追加。
・iPhoneにはSafariの共有メニューから追加する手順を案内。
・AndroidにはChromeの追加手順と、端末が対応する場合のインストールボタンを用意。
・管理者/開発者の入口、正解率・回答数・学習時間の比較、拠点絞込を維持。

利用上の補足
初回登録・成績提出には通信が必要です。
オフライン端末のデータを遠隔で即時消去することはできません。
古いアプリの端末内履歴はv13に更新し登録を行うまで遠隔消去の対象になりません。
削除後に新しい登録を行った場合は別のプレイヤーNo.として扱います。
登録は同じ端末・同じブラウザで使用してください。別端末の履歴は自動統合されません。
ホーム画面アプリとブラウザの保存領域が分かれる端末では、追加後のアイコンから登録・学習します。
ホーム画面への追加には利用者自身の操作が必要です。OSやブラウザによりボタン名・位置が異なります。
アプリ内ブラウザで開いた場合はSafariまたはChromeで開き直してください。
学習時間は問題画面で計測し、画面非表示・採点完了後・2分を超える無操作部分を除きます。
過去の学習時間は復元できず「未計測」です。比較は最新提出時点の累計で、未提出分は反映しません。
バックアップには登録を復元するための情報が含まれます。本人が保管してください。

確認済み
登録未完了・通信失敗時の学習ブロック、登録保持、歯車変更、登録済み成績提出。
10個の学習・成績画面を直接開いた場合の登録必須動作。
未提出者の一覧、対象者の名前確認、個別削除、他人のデータ保持、削除後の端末初期化。
管理者に削除UIがないこと、iPhone手順、Androidのインストール要求のクリック実行。
クラウド側もトランザクション内の検証データで権限・対象限定削除・再送拒否を確認しロールバック。
PDFは日本語フォントを埋め込み、両方A4各1ページです。
実機のiPhone/Androidでの追加操作そのものは未確認です。
