スキマル保全士 Manager閲覧専用パッチ

アップロードするファイル:
- admin.html（上書き）
- service-worker.js（上書き）
- viewer.html（新規）
- viewer-manager.js（新規）
- viewer-manager.css（新規）
- manager-viewer-admin.js（新規）

使い方:
1. GitHub mainへ6ファイルをアップロード
2. Managerへ今まで通り管理者ログイン
3. 「閲覧パス設定」を押す
4. 8文字以上の閲覧用パスワードを設定
5. 共有相手はManagerログイン画面の「閲覧用パスワードで見る」から入る

閲覧者ができること:
- 総合分析
- 学科分析
- 実技分析
- プレイヤー詳細・年度別過去問成績の確認

閲覧者ができないこと:
- データ削除
- 試験日変更
- メッセージ送信
- 閲覧パスワード変更

Supabase側のテーブル・RPCはすでに設定済みです。
