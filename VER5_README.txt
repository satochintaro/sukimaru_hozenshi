スキマル保全士 Ver 5.0.0

【実装内容】
・初回起動時に匿名のプレイヤーNo.を自動発行
・社員番号、所属、メールアドレスは登録しない
・提出履歴はSupabaseへ毎回追加保存
・管理者一覧はプレイヤーNo.単位で1人1行表示
・最新正答率、前回比、初回比、提出回数、最終提出日時を表示
・個人詳細で正答率推移グラフ、過去最高、提出履歴を表示
・同じ表示名の別プレイヤーには「同名あり」を表示

【公開前に必ず実施】
1. SupabaseのSQL Editorで V5_UPDATE.sql を実行
2. その後、GitHubへ全ファイルをアップロード
3. GitHub Pagesの反映後、ブラウザを再読み込み

【既存データ】
Ver 4.9以前の履歴にはプレイヤーNo.がないため、管理画面では「旧データ」として表示されます。
Ver 5.0以降に提出した履歴から、プレイヤーNo.単位で正確に集計されます。

【プレイヤーNo.について】
プレイヤーNo.は各ブラウザ端末内に保存されます。
ブラウザデータを削除した場合、別のプレイヤーNo.が新しく発行されます。
