# v16.82 直前模試とランキング調整

限界チャレンジの直下に「直前模試」を追加。1級・2級で各200問の独自○×問題から出題します。共通160問、級別40問ずつのため、重複を除いた新規設問数は240問です。既存の過去問バンクの設問・解答は変更しません。

- パターンA／B：各100問。両パターン間で設問IDの重複なし。5科目各20問、○50問／×50問。順序は開始時にシャッフル。
- 苦手優先：200問から重複なく100問。各科目最低10問を確保し、残りを重み付き抽出。本人の過去問・直前模試の誤答と、全体の誤答傾向を優先。誤答記録がなければ全体傾向と各分野から出題。
- 重点ポイント：級ごとに25項目。出題の確約・今年度問題の予告はしません。
- 解答の変更、あとで確認マーク、100問の回答一覧、中断・再開に対応。時間制限なし。採点前は正解を表示しません。
- 採点後に科目別結果・全問解説・誤答の解き直し。解き直しは採点済みの点数・累計回答数を増やしません。
- 採点時に学科へ100回答と正解数を一度だけ加算。未回答は不正解。採点前の中断分は回答数に加算しません。測定時間は学科学習時間へ含みます。
- 模試履歴は直近20回を保持。累計回答・正解・完了回数・ベストは履歴表示件数によらず維持します。
- 1000問のランキング記録は維持。上限1000問は据え置き、4桁の文字サイズと余白を調整し「完全制覇」を表示。同記録の同順位ルールも維持します。

## 保存と互換性

既存の `skimaruData`／`skimaru-grade1-v16` 内に `finalMock` を追加して既存のバックアップ対象に含めます。既存の通常学習・限界チャレンジとは別の台帳で管理し、集計時に合算します。他タブの新しい台帳を古いホーム画面が上書きしないよう改修しています。DBのスキーマ変更・ランキングのリセットはありません。

新規ファイルは app/final-mock*。更新対象は共有ダッシュボード、両級入口、ランキングロビー、累計・時間・同期の集計処理、サービスワーカー、タイトルの版数です。再配置や旧ファイルの削除は行いません。
