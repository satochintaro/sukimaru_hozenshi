# スキマル保全士 Ver 4.9.0（Supabaseクラウド集計版）

## 最初に1回だけ行う作業

1. Supabase Dashboard の **SQL Editor** を開く。
2. `SUPABASE_SETUP.sql` の内容を貼り付けて **Run**。
3. **Authentication > Users** でマネージャー用ユーザーを1名作成する。
   - メールアドレスとパスワードを設定
   - メール確認済み（Auto Confirm）で作成
4. Authenticationの設定で、一般利用者が勝手に管理者登録できないよう **新規サインアップを無効**にする。
5. このフォルダの中身をGitHub Pagesの公開フォルダへ上書きする。

## 利用方法

- プレイヤー：ログイン不要。回答後「クラウドへ提出」で `exam_results` に保存。
- マネージャー：モード選択からマネージャーを開き、Supabase Authのメール・パスワードでログイン。
- オフライン提出：端末内に保留し、通信復旧時に自動再送。

## セキュリティ

- GitHub内に入っているのはPublishable keyのみ。
- Secret key / service_role keyは使用していない。
- RLSにより、未ログイン利用者はINSERTのみ。SELECTとDELETEは認証済み利用者のみ。
- Authで一般サインアップを許可したままだと、登録した利用者が管理者権限を持つため、必ず新規サインアップを無効にしてください。

## 更新反映

GitHubへ上書き後、スマホのホーム画面アプリを完全終了して開き直してください。古い画面の場合はブラウザで公開URLを開いて再読み込み後、ホーム画面版を再起動します。
