使い方
1. 既存プロジェクトをバックアップしてください。
2. ZIPを展開し、README_v10.txt、verification_v10.json以外のファイルを、既存プロジェクトのルートへ追加・上書きしてください。
3. 更新ファイルを公開後、ページを再読み込みしてください。必要に応じて強制再読み込みしてください。

画面・動作
・1問ずつの設問文と選択肢を表示。
・選択肢をタップすると即時保存。別の選択肢へ変更可能。
・課題切替、前後移動、再読み込みでも回答を保持。
・原本画像をタップして全画面表示。ピンチで拡大し、指で移動。ダブルタップで閉じる。
・全問回答後にまとめて採点。途中では正解を表示しない。
・採点済みの回答は編集をロック。再挑戦時は当該年度だけリセット。
・既存の保存キーと解答形式を維持。2025年度の集計データ連携も維持。
・選択課題は2023年度と同様にAのみ。旧B回答は選択課題の範囲だけ解除し、共通設問の回答と記録済み履歴を保持。

変更しない対象
タイトル画面、PLAYER、MANAGER、学科、実技年度メニューは変更していません。
GitHubへの反映・公開作業は行っていません。
