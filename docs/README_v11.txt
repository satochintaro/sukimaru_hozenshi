変更内容

・管理・閲覧画面に拠点絞り込み、名前/No.検索、拠点表示を追加。

・提出成功後は通知を解除。通信失敗は「送信待ち」として保存し、オンライン復帰時に再送。
・学習画面の設定「名前変更」からも拠点と名前を変更できます。
・2025年度の設問表示とノッチ対応を維持。

通知について
通知はこの端末のアプリ内に表示されます。学科はホーム、実技はメニューと年度別画面で確認できます。
アプリを閉じている間のプッシュ通知・メール送信は含みません。
登録と未提出データは使用中のブラウザに保存されます。参照画面にはクラウドへ提出された成績が表示されます。
初回更新時、以前の提出済み状態を端末で判定できない成績は提出を促します。一度提出すると以降は新しい成績のみ判定します。

確認内容
新規登録必須、既存データ引き継ぎ、拠点編集、学科/実技/年度別学科の提出判定、拠点絞込・検索。
送信成功/通信失敗/再送はテスト用応答で確認。実際のクラウドにはテスト成績を登録していません。
2022年度76問、2024年度74問、2025年度72問の回答・保存・採点も確認済み。
